# VIDEO_SCRIPT.md — 3-minute demo (record today)

Target ~3:00. Every beat is mapped to a judging criterion so the judges' boxes
get ticked explicitly. Speak the **SAY** lines; show the **SHOW** actions.

## Setup before you hit record (5 min)
1. Start local backend: `cd backend && .\.venv\Scripts\uvicorn attest.main:app --port 8000`
2. Start frontend: `cd frontend && npm run dev`  (local dev talks to the local backend)
3. Open two tabs: `http://localhost:3000` (local, for generation) and
   `https://attest-black-two.vercel.app` (live, for verify/tamper).
4. Warm the live site once (click around) so nothing cold-starts on camera.
5. Screen at 1280×800, browser zoom 100%, hide bookmarks bar.

## [0:00–0:20] Hook + problem  · criterion: Real-World Utility
**SHOW:** Live landing page (`attest-black-two.vercel.app`), the animated seal.
**SAY:** "From August 2026, the EU AI Act Article 50 requires every AI-generated
asset to carry provenance. For a fintech or marketing team, that's a compliance
problem on every image they ship. ATTEST makes it a three-second pipeline step —
generate, sign, store, verify."

## [0:20–1:10] Generate & sign  · criteria: Use of Genblaze + B2
**SHOW:** Local Console (`localhost:3000/console`). Type a brief, click
**Generate & sign**. Let the SSE pipeline visualizer run.
**SAY:** "This runs on the Genblaze SDK. The brief is classified by DeepSeek on GMI
Cloud, the image generated by Seedream — with fallback chains if a provider fails.
Then our custom Genblaze ComplianceSink takes over: it canonicalizes the manifest,
signs it with an Ed25519 key only our pipeline holds, and writes the asset and the
signed manifest to Backblaze B2 — under Object Lock, governance mode, 365-day
retention, so the record is tamper-evident at the storage layer."
**SHOW:** Point at the pipeline steps (classify → generate → sign → B2 Object Lock →
audit) and the audit log populating.

## [1:10–1:55] Verify (public, no login)  · criteria: Utility + Production
**SHOW:** Switch to the LIVE tab → `/verify` → click **Verify a signed asset**.
**SAY:** "Anyone — a regulator, a partner, an auditor — can verify with no account.
The verifier re-fetches the bytes, recomputes the SHA-256, checks the Ed25519
signature against our trusted key, and walks the revision lineage. Green across the
board — a Certificate of Provenance."
**SHOW:** The green "Certificate of Provenance", the provenance card (signer key,
B2 Object Lock, watermark). Click **Download certificate** for a beat.

## [1:55–2:35] Tamper — the money shot  · criteria: Utility + Production
**SHOW:** Scroll to the **Tamper playground**. Click **Tamper the image**.
**SAY:** "Watch what happens if a single pixel changes. This alters the image in the
browser and re-hashes it live — invisible to the eye…" (the seal flips to red)
"…but the hash no longer matches the signed manifest. Tamper detected, instantly.
The bytes and the signature are inseparable."
**SHOW:** The red TAMPERED seal + the hash mismatch (signed vs current). Click
**Restore original** → back to verified.

## [2:35–3:00] Depth + close  · criteria: Genblaze + Production
**SHOW:** GitHub repo (CI green badge), then the Genblaze Mode 2 PR page.
**SAY:** "ATTEST is production-minded: CI, a full test suite, security-hardened
storage, and a provider failsafe so a demo never dies. And we gave back — an
upstream Ed25519 Mode 2 signing contribution to the Genblaze SDK itself. Provenance
for the AI-media era, built on Genblaze and Backblaze B2."
**SHOW:** End on the seal / landing.
